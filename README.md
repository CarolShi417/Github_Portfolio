每次修改 `styles.css` 或 `content-marketing-text.js` 后，记得同步更新 `content-marketing.html` 里的版本号，例如 `?v=20260710-2`。手动上传时至少上传 `content-marketing.html`、`styles.css`、`content-marketing-text.js`；如果新增图片，也上传 `assets/social-media/` 对应文件。上传后等待 GitHub Pages 部署完成，再用带 `?v=` 的网址刷新查看。
