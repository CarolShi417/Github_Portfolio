# WATCHVERSE Typography System — current working scope

This section applies from **Content Strategy** through **Performance Visualized** only. The fixed top-navigation HIGHLIGHT text is intentionally unchanged.

## Audit before consolidation

| Font family | Current use in the WATCHVERSE area | Status |
| --- | --- | --- |
| Arial / Helvetica / sans-serif | All visible WATCHVERSE copy, headings, lists and dashboard text | Active |
| Poppins / Arial / Helvetica / sans-serif | Defined for project-card styles elsewhere, not used inside WATCHVERSE | Not active in this area |

Reference note: the Of the Oak reference uses its own `Oracle` font at regular 400 weight. This project uses system-font alternatives so it remains free to publish and does not require a font licence.

## Consolidated font roles (maximum three)

| Role | Font stack | Weight | Areas |
| --- | --- | --- | --- |
| Display | Helvetica Neue, Arial, sans-serif | 400 | WATCHVERSE title; section titles including The Challenge, My Approach, Results and Performance Visualized |
| Text | Arial, Helvetica, sans-serif | 400 | Content Strategy intro, overview copy, lists, Results copy, dashboard labels and navigation inside the dashboard |
| Data | Courier New, Courier, monospace | 400 | Dashboard platform name and numeric metric values |

## Consolidated size roles (maximum five)

| Size role | Responsive size | Areas |
| --- | --- | --- |
| Display | 64–112px | WATCHVERSE title |
| Section | 32–48px | Content Strategy kicker; The Challenge, My Approach, Results and Performance Visualized titles |
| Body | 17–20px | Intro paragraphs, overview copy, Challenge / Approach lists and Results copy |
| Small | 13px | Dashboard labels, tabs, sync status and metric labels |
| Data | 24–32px | Dashboard platform name and metric values |
